# 手稿编序

档案员按段上传重叠扫描的 CSV 清单，系统汇总各段扫描顺序与手工补记的
两页先后，核对无环后排出手稿页序，并提供阅览目录 CSV。另可上传逐页
转写，按字面检索原文落在哪些纸页（含确定的跨页命中）。

## 启动

```bash
docker compose up --build   # 打开 http://localhost:8000
```

本地开发（无需 Docker）：

```bash
pip install -r requirements-dev.txt
python run.py               # 或 flask --app run:app run
python -m pytest tests/ -v  # 测试
```

数据存 SQLite，路径由环境变量 `MSO_DB` 指定（容器内默认
`/data/manuscript.db`，本地默认 `instance/manuscript.db`）。

## 规则

- **扫描段 CSV**：每行一个纸页标识（取第一列，首行可为 `page_id` 等表头），
  行序即该段扫描顺序；同一页在各段沿用同一标识。相邻行产生“先后”证据。
- **重扫**：同名段重传只替换本段证据（补页、改序均可），他段与他证保留；
  若新证据与保留证据成环，整笔退回，旧段原样。
- **补记**：登记一对页的先后；同一对重报只记一次（幂等）；成环则退回，
  并列出环上每条边的来源（扫描段行号 / 补记编号）。
- **并发**：所有变更在 `BEGIN IMMEDIATE` 事务内“先核对、后落库”，
  SQLite 写锁使并发提交串行化，核对读到的即实际入库时刻的证据。
- **阅览目录** `GET /catalog.csv`：随证据实时计算。排不出唯一页序时
  返回 409 停供（不给旧目录），并指出一对先后待定的页。

### 转写与检索

- **转写 CSV**：每行「纸页标识,转写全文」（首行可为 `page_id,text` 表头）。
  正文含逗号时按逗号原样接回；含换行时按 CSV 引号规则书写。
  上传按页替换：只覆盖本批列出的纸页，其余页转写保留。
- **整批退回**：任一条纸页为空、纸页未知或同批重号，则整批 400 退回，
  一条都不入库，并列出全部问题。
- **字面检索** `GET /api/search?q=...`：不做大小写折叠，列出命中片段
  （带少量上下文）与纸页标识，分页内、跨页两组返回。
- **跨页命中**：只认「前页末尾接后页开头」这一种切分；且要求该两页在
  *所有* 符合当前证据的线性页序里都同向紧挨。判定用一次传递闭包
  （见下），不枚举页序。未转写的纸页也参与判定——它们可能正把候选
  两页隔开。全册页序未定时，页内命中与确定的跨页命中仍照常给出。
- **证据即时生效**：重扫段或新增补记即使不改动任何转写，也会改变
  相邻关系，后续检索立即按新证据判定。
- **同一快照**：一次查询的转写与页序证据在同一只读事务里读取，
  不会把两次提交的状态拼在一起。

**紧邻判定（不枚举页序）**：把全部证据边做一次传递闭包。设证据唯一
确定 first 先于 second，则二者在所有合法页序里都紧挨，当且仅当
「first 及其所有祖先」与「second 及其所有后代」覆盖全书所有纸页——
否则总存在某页可以排到二者之间。复杂度 O(V·E/字长)。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 网页 |
| GET | `/api/state` | 段、补记、已入库转写、唯一页序或待定页对 |
| POST | `/api/segments` | 上传/重扫段（multipart：`name` + `file`） |
| POST | `/api/notes` | 补记（JSON：`{"a": "...", "b": "..."}`） |
| POST | `/api/transcripts` | 上传转写（multipart：`file`），按页替换、整批校验 |
| GET | `/api/search?q=...` | 字面检索转写，返回页内与跨页命中 |
| GET | `/catalog.csv` | 唯一时 200 给 CSV；否则 409 给待定页对 |

## 结构

- `app/logic.py` — 证据图、成环检测（三色 DFS）、唯一拓扑序（Kahn）、
  转写校验、传递闭包紧邻判定与字面检索
- `app/routes.py` — 路由与事务边界
- `app/db.py` — SQLite 连接与模式
- `tests/test_app.py` — 原有 13 项测试，加转写上传/检索/跨页判定等，
  共 31 项；其中含“紧邻判定 vs 枚举页序”的随机对照测试
